# Codexa Page Topology

1. **Navigation** — fixed 72px overlay; desktop logo, five links, contact and primary CTA; mobile/tablet show logo only.
2. **Hero** (`#home`) — centered display copy, white CTA, teal radial glow, real code-window image, horizontally looping trust strip.
3. **Benefits** — section intro above a three-column feature matrix with a teal ASCII brain centered between four text cells.
4. **Features** — three alternating 500px rows pairing CSS-rendered product mockups with feature copy and three checklist bullets.
5. **How it works** — section intro and three equal cards: integration orbit, workflow status list, and activity graph.
6. **Feature tabs** — click-driven tab bar with three code/copy states; remains three-state on narrow screens with previous/next controls.
7. **Comparison** — split “Other Tools” versus Codexa checklist panel.
8. **Pricing** — monthly/yearly click toggle; three plan cards and four reassurance items.
9. **Testimonials** — 2x3 desktop card grid, single-column mobile stack, followed by a trust strip.
10. **FAQs** — two-column desktop intro/accordion; stacked on narrow screens. Rows expand independently.
11. **Footer** — CTA glow, newsletter form, centered mark, three link groups, copyright.

The page uses the document scroll container with Lenis on the source. There is no scroll snap. Sections are normal flow content; only the navigation is fixed. Desktop content max-width is 1200px with 40px outer page padding. At 768px and 390px the layout becomes single-column with 28px horizontal padding.
