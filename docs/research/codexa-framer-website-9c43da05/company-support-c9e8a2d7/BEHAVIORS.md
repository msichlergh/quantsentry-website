# Support Behaviors

- The page uses normal document scrolling beneath the shared fixed 72px navigation.
- The Support menu link targets `#support`, which is the page section itself.
- Full name, email, phone number, reason, and message are required native form fields.
- Empty submission is blocked by native constraint validation. Valid demo submission stays on-page because the clone has no backend.
- Contact Sales uses the shared outlined-pill hover/focus treatment.
- Inputs shift to the teal focus border; the submit button lightens on hover/focus.
- Shared CTA/footer content reveals when it intersects the viewport; reduced-motion users receive the final visible state immediately.
- At `max-width: 768px`, the two-column contact shell stacks and gains the source 12px side rails.
