# Careers Page Topology

1. Shared 72px Codexa navigation.
2. Hero: 384px desktop / 345px mobile, grid texture and right-bottom teal bloom, left-aligned eyebrow, title, and description.
3. Join-team introduction: two equal desktop columns; mobile stacks heading, copy, and anchor CTA.
4. Culture section: centered headline followed by six fixed-height icon cards in a 3x2 desktop or 2x3 mobile grid.
5. Openings section: sticky-style left headline column beside six job rows on desktop; stacked heading and cards below 768px.
6. Shared Codexa CTA/footer.

The page uses the normal document scroll container. The openings list is the only main-section viewport-triggered reveal. Buttons use hover/focus label-sliding states and all job CTAs navigate to local detail routes.
