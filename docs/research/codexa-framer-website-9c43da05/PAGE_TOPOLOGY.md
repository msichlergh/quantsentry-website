# Codexa page topology

All cloned pages use a fixed 72 px navigation, a centered 1200 px content shell with subtle vertical borders, and the shared multi-column Codexa footer. The local route namespace is `/codexa`.

## Shared inner-page structure

1. Navigation
2. Centered page shell
3. Page-specific hero, content sections, and CTA
4. Footer

Product and company pages use a 357–415 px inner hero followed by bordered content bands. Legal pages use the same hero and a single readable policy column. Blog articles use an editorial hero, a 16:9 cover, a two-column article/author layout, and a three-card related-article section. The 404 page is intentionally compact and omits the footer.

Desktop and 390 px mobile source captures live in each page-specific directory under `docs/design-references/codexa-framer-website-9c43da05/`.
