# Career Detail Page Topology

1. Shared 72px Codexa navigation.
2. Centered job hero with location/schedule metadata, title, and one-line summary.
3. Bordered article well centered inside the 1200px main frame.
4. Ordered sections: Overview, What You’ll Do, What We’re Looking For, Nice to Have, About Codexa, How to Apply.
5. White `Apply now` button linking to local support.
6. Shared Codexa CTA/footer.

The Product Manager source page intentionally renders the complete six-section article twice before its single Apply button. The clone preserves this visible source behavior.
